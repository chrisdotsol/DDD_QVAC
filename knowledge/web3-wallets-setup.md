# Setting Up Web3 Wallets Safely (MetaMask, Phantom, etc.) 2026

## MetaMask (Ethereum + EVMs)
1. Install from official site or browser store.
2. Create new wallet → Secure backup of 12-word Secret Recovery Phrase (offline).
3. Set strong password + enable 2FA/biometrics where available.
4. Add networks via Chainlist.org (verify RPCs).
5. For Solana: Use bridges or dedicated Solana wallets.

## Phantom (Solana-focused)
1. Download from phantom.com or official app stores.
2. Create wallet → Backup 12-word phrase (offline, metal recommended).
3. Enable biometrics/PIN.
4. For advanced: Hardware wallet integration (Ledger).

## General Safety Rules for All Hot Wallets
- Use only for small daily amounts; cold storage for large holdings.
- Never share seed/private keys.
- Revoke approvals regularly (revoke.cash or wallet tools).
- Use separate wallets for airdrops/DeFi vs. main holdings.
- Bookmark official dApps; avoid search engine links.
- Enable transaction simulation/previews where available.
- Keep OS/browser updated; use antivirus.
- Consider wallet connect with hardware for signing.

**Pro Tip**: For maximum safety — Hardware wallet + hot wallet for interaction (connect via USB/Bluetooth only when needed).
