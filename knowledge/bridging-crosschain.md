# Bridging & Cross-Chain Stablecoins Safely

## Popular Bridges (2026)
- **Official**: Wormhole, Axelar, LayerZero, Across, Synapse.
- **Native**: Solana → Ethereum via official bridges or CCTP (Circle Cross-Chain Transfer Protocol for USDC).

## Safe Bridging Steps
1. **Research Bridge**: Check TVL, audits, incident history on DefiLlama or L2Beat.
2. **Small Test Transfer**: Send $10–50 first.
3. **Verify Addresses**: Confirm contract addresses on official docs.
4. **Gas Fees**: Ensure sufficient native token (ETH, SOL) on both sides.
5. **Time Delays**: Some bridges have finality periods.
6. **Hardware Wallet**: Sign from cold storage.

**Risks**: Bridge exploits (historical losses in billions). Prefer native issuance (e.g., native USDC on Solana) over bridged versions when possible.

**Best Practice**: Use Circle's CCTP for USDC where available — it burns and mints natively.
