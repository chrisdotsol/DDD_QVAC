# Hardware Wallets (Ledgers) – Safe Setup & Use 2026

## Popular Options
- **Ledger (Nano S Plus / Nano X / Stax)**: Secure Element chip for isolation. Bluetooth on Nano X (use cautiously).
- **Trezor (Model T / Safe 5)**: Open-source firmware emphasis. Touchscreen on higher models.

## Setup Steps (General)
1. Buy **directly from official website** (never resellers/Amazon to avoid tampered devices).
2. Unbox and check for tampering.
3. Install latest firmware via official app (Ledger Live / Trezor Suite).
4. Create **strong PIN**.
5. Write down **24-word recovery phrase** on provided card (or metal backup). Store offline in multiple secure locations (fireproof safe, different physical sites). **Never photograph or store digitally**.
6. Verify phrase on device.
7. (Optional) Add passphrase for extra wallet.
8. Install apps for relevant chains (Ethereum for USDC, Solana, etc.).

## Security Best Practices
- Never enter seed on computer/phone.
- Always verify transaction details on the device screen (clear signing).
- Keep firmware updated.
- Use on clean, updated devices.
- For max security: Air-gapped signing where possible.
- Test small recovery with a tiny amount first.

**Ledger vs Trezor**: Ledger emphasizes hardware isolation; Trezor emphasizes open-source auditability. Both are strong when used correctly.
