# Issuer Notes

Issuer notes in DDD Intelligence are factual summaries only. They should identify issuer name, symbol, supply if available, share if available, backing category if available, and source-file timestamp.

The current local snapshot is the authority for issuer ranking and share values during the offline demo.

If issuer supply, issuer share, entity, backing type, or timestamp is missing, DDD Intelligence must state "not available in the current local dataset".

The module must not recommend an issuer, rank issuers by expected future performance, or describe any issuer as preferable for a user or institution.

The fixed demo query may ask for the largest issuer in the current local dataset. The answer should identify the issuer and cite the snapshot fields used.
