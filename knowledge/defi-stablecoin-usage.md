# Using Stablecoins in DeFi Safely (2026)

## Common Use Cases
- **Lending/Borrowing**: Supply USDC/USDT on Aave, Compound, Morpho for yield.
- **Liquidity Provision**: Add to pools on Uniswap, Orca (Solana), etc.
- **Yield Farming**: Farms, vaults (Yearn, Beefy).
- **Payments & Remittances**: Low-fee cross-border transfers.
- **Collateral**: Back loans or mint synthetic assets.

## Safety Checklist
1. **Audit Protocols**: Check DefiLlama, RugDoc, or recent audits (Trail of Bits, etc.).
2. **TVL & History**: Prefer battle-tested protocols with high TVL.
3. **Impermanent Loss**: Understand risks in volatile pairs.
4. **Contract Approvals**: Approve only necessary amounts; revoke after use (use revoke tools).
5. **Slippage & MEV**: Set conservative slippage; use private RPCs if available.
6. **Chain Selection**: Ethereum (secure but expensive), Solana/Base (fast/cheaper but different risks).
7. **Exit Strategy**: Test small withdrawals first.

**Advanced**: Use hardware wallet + multisig (Gnosis Safe) for large positions. Monitor positions daily.

**Warning**: DeFi yields come with smart contract and liquidation risks. Start with tiny amounts.
